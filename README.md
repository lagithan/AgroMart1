# 🌱 AgroMart1

AgroMart1 is a **simple e-commerce platform** designed for the agriculture domain.  
It allows farmers to list their products and buyers to browse, search, and place orders through a clean online marketplace.

---

## ✨ Features

- 🏷️ Product listings for farm produce  
- 🔍 Search & filter products by category / price  
- 🛒 Buyers can browse and place orders  
- 📦 Sellers can add, edit, and manage products  
- 🔑 User authentication (login / signup)  

---

## 🛠 Tech Stack

| Layer        | Technology |
|--------------|-------------|
| Frontend     | React.js |
| Backend      | Node.js (Express.js) |
| Database     | MongoDB |
| State Mgmt   | React state / hooks |
| Styling      | CSS |

---

## 📌 Short Description

AgroMart1 is a **basic full-stack e-commerce application** built with  
**React.js (frontend)**, **Node.js (backend)**, and **MongoDB (database)**.  

It is a **local development project** (no deployment yet) created to demonstrate a simple online marketplace for agriculture products, where farmers can sell and buyers can purchase directly.
